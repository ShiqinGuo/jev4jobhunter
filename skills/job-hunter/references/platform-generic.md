# 其他招聘网站

当前执行适配器支持 BOSS。其他站点可分析用户提供的完整 JD、链接与申请材料；未适配的搜索、表单、上传和提交不能宣称已经执行，也不能绕过入口裸操作。

按 [matching.md](matching.md) 比较岗位，保留来源、薪资原文、职责与未知条件。搜索摘要不能代替全文；职位已关闭或缺少正文时不从相似岗位补写。

职位身份优先采用稳定 requisition ID；没有时保留完整规范化 URL，不能随意删除可能标识岗位的 query 参数。跨平台仅在明确同一职位时关联 sameOpportunityAs，不凭公司和标题相同合并。

本地可准备申请表答案与附件清单，工作许可、签证、搬迁、薪资、到岗等缺项保持待答。接入新站点属于插件维护任务，须先实现并验证相应入口。

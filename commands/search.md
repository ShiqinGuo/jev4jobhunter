# /job-hunter:search

加载本插件的 [job-hunter Skill](../skills/job-hunter/SKILL.md)，执行 search 意图。

用户参数：$ARGUMENTS

读取 matching.md；按用户选择的 Android 或 Kimi 网页入口采集完整 JD 并比较。只读招聘平台，不顺带投递或处理聊天。缺画像仍可按已知条件搜索，缺事实标未知。
